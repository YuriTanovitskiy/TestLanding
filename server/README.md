# Пробная онлайн-запись

Запуск: `npm run dev`, затем открыть адрес Vite (обычно http://localhost:5173).
Локальный API работает также с `npm run preview`. Простая раздача папки `dist`
без Vite не поддерживает сохранение записей.

Записи сохраняются в `.local-bookings/bookings.json` в корне проекта. Файл
содержит контактные данные, исключён из Git и закрыт от файловой раздачи Vite.
GET `/api/bookings?date=YYYY-MM-DD` возвращает только занятое время.
POST `/api/bookings` проверяет поля, дату по Алматы и отсутствие брони.
Один процесс последовательно выполняет проверку и атомарное сохранение файла.
Повторная запись на занятое окно возвращает HTTP 409.

Записываться можно на ближайшие 7 рабочих дней с завтрашнего дня,
понедельник–суббота, в 09:00, 10:00,
11:00 и 12:00. После сохранения открывается WhatsApp с текстом; клиент сам
отправляет сообщение. Сохранённое окно остаётся занятым даже без отправки.
В пробной версии отмена и административное управление не предусмотрены.

Проверка: `node --test server/bookingPlugin.test.mjs` (Node.js 24).
Тест использует временное хранилище, не меняя реальные пробные записи.

Это локальный прототип для одного серверного процесса. До публикации нужен
постоянный сервер с базой данных и уникальным ограничением на дату/время,
административное управление записями и защита от массовых заявок. Плагин Vite
не является сервером для публичного сайта.
